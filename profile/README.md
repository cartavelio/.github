# Cartavelio

Cartavelio hosts forks of [transpect](https://github.com/transpect), an open-source toolchain for document conversion and publishing. The original tools were built by the transpect project and its contributors.

## transpect forks

- [CoCoTeX](https://github.com/cartavelio/CoCoTeX) is Xerif’s LuaLaTeX typesetting backend. [Original transpect repository](https://github.com/transpect/CoCoTeX)
- [xerif-latex](https://github.com/cartavelio/xerif-latex) contains the LaTeX packages and support files Xerif uses at render time. [Original transpect repository](https://github.com/transpect/xerif-latex)
