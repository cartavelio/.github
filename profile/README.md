# Cartavelio

We build tools for turning manuscripts into typeset books. Our public repositories focus on document conversion and layout for web, EPUB, and print.

## Rendering tools

- [Xerif](https://github.com/keethburu/xerif) converts structured XML to LaTeX for typesetting.
- [Hub2HTML](https://github.com/keethburu/hub2html) converts Hub XML to XHTML for HTML and EPUB workflows.
- [CoCoTeX](https://github.com/cartavelio/CoCoTeX) provides the LuaLaTeX typesetting backend used by Xerif.
- [xerif-latex](https://github.com/cartavelio/xerif-latex) contains the generated LaTeX packages and support files used at render time.

These repositories are maintained forks of [transpect](https://github.com/transpect) projects.
